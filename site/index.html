Replicabilità (pacchetto script)

Il progetto separa presentazione (pagina web) e contenuti (manifest JSON). Gli script permettono di rigenerare il manifest e verificarne l’integrità.

  1. python scripts/build_manifest.py → genera il manifest con metadati e checksum
  2. python scripts/serve_local.py → avvia un server locale per testare la pagina
  3. (opzionale) python scripts/verify_checksums.py → verifica SHA-256 dei PDF
